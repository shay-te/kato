# Why Use Kato

> **Ship more tickets with an AI agent you can actually trust — from one screen,
> with one approval popup, behind security you control.**

Coding agents are powerful but scary: they run shell commands, touch
credentials, and sprawl across terminals and tabs. Kato turns that chaos into a
**single, governed cockpit** — so a team can put an agent on real tickets
without losing sleep over what it might do.

## Do more, in one place

- **All your tasks in a single pane.** Every ticket the agent is working — across
  every repo — lives in one tabbed UI.
- **One agent for every tracker & git host.** YouTrack, Jira, GitHub, GitLab,
  Bitbucket — Kato picks up assigned tickets and opens PRs wherever they belong.
- **Run on the agent you like.** Claude, Codex, or OpenHands behind the same UI;
  pick the model and effort per task.
- **End-to-end busywork handled** — clone, branch, code, test, open the PR, post
  a summary, and fix or answer review comments in-thread.

## Approve everything from one popup

- **Central approval popup.** Every permission request — even from a backgrounded
  task — surfaces in one modal. No hunting across windows for the prompt blocking
  your work. See [Approvals](./approvals).
- **Full control on every prompt.** See the exact command/tool and choose Allow,
  Allow-always, or Deny (with a reason the agent reads and adapts to).
- **One screen to approve repositories** Kato may touch — instead of trusting a
  config file you can't see.
- **Nothing ships without you.** No auto-commit, no auto-push, no auto-resolve.

## Security that's visible, not hand-wavy

- **Action Guard** blocks credential reads, network exfiltration, remote-exec,
  and sandbox escapes, and asks before dual-use actions. Tune Block / Ask / Allow
  per category; a no-legit-use floor can never be loosened. See [Security](./security).
- **Out-of-folder writes always ask** — even scratch paths like `/tmp`.
- **Isolated per-task workspaces** — each task runs in its own sandboxed clone.
- **Tamper-evident audit log** of every guarded decision.

## See and steer the work

- **Live diff viewer + inline comments** — comment on any line and Kato re-runs
  with it as a new instruction.
- **Smart PR-comment handling** — fixes or answers reviewer comments; ignores
  comments that @-mention a *human* (not the bot).
- **Gets better over time** — lessons from past tasks feed future runs.

## The bottom line

Kato gives a team the throughput of an autonomous agent with the oversight of a
senior reviewer — **one cockpit, one approval flow, security you can see.**
