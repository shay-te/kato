# What is Kato

**Kato is an autonomous coding agent with a governance cockpit.** Assign it a
ticket in YouTrack, Jira, GitHub, GitLab, or Bitbucket and Kato clones the repo,
writes the code with your chosen agent (Claude, Codex, or OpenHands), runs your
tests, opens a pull request, and posts a summary back on the ticket. If reviewers
leave comments, Kato fixes them or answers in the thread.

The difference from running a raw coding agent in a terminal: **you stay in
control the whole time, from one screen.**

## What you get

- **One UI for every task** — across every repo and every ticket platform.
- **One approval popup** — every permission request lands in a single modal,
  even for tasks running in the background.
- **Security you can see** — Action Guard blocks the dangerous patterns and asks
  before dual-use actions, all tunable from the UI.
- **Nothing ships without you** — no auto-commit, no auto-push; you review the
  diff and click **Done — Push**.

## Who it's for

Teams that want the throughput of an autonomous agent **without** handing it
unsupervised shell access. Kato is the layer that makes "let an AI work our
backlog" a decision you can defend.
