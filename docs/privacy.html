kato

Privacy policy

Last updated 13 October 2026

Kato collects no data.

Kato runs on your computer. It has no telemetry, no analytics and no crash reporting, and it sends nothing to the Kato project or its maintainers.

What stays on your computer

Everything Kato keeps is in the .kato folder in your home folder:

  • your settings, including the tokens and keys you enter;
  • each task's workspace, with its copies of your repositories;
  • chat history, review-loop records and the log file (logs/kato.log).

Uninstalling the desktop app leaves this folder in place. Delete it to remove everything Kato stored.

Where Kato connects

Kato connects only to the services you set up, and to check for updates:

  • Your coding agent — Claude Code, Codex or OpenHands. The agent sends your instructions and the code it reads to the AI provider you use with it (for example Anthropic, OpenAI or OpenRouter), under that provider's terms.
  • Your issue tracker — YouTrack, Jira, GitHub, GitLab or Bitbucket — to read the tasks assigned to you and post the updates you allow.
  • Your git host — GitHub, GitLab, Bitbucket or Azure DevOps — to copy repositories and, when you choose, push branches and open pull requests.
  • The npm registry, to check whether your agent's command-line tool has a newer version. Only the tool's name is sent.
  • Security scans, if you turn them on. npm audit sends a project's list of dependencies (names and versions) to the npm registry, and Safety downloads PyUp's vulnerability list.
  • OpenRouter's public model list, when OpenHands is set up to use OpenRouter, so the settings page can offer its models. No key is sent.
  • GitHub, where the desktop app checks for and downloads its own updates.
  • Docker image registries, if you use the optional sandbox, to download the images it is built on.

This website

This site is hosted on GitHub Pages, and GitHub may log visits as described in the GitHub Privacy Statement. The site itself has no analytics and sets no cookies. It asks GitHub only for the latest release, to link its downloads.

Questions and changes

Ask in the project's GitHub issues. Any change to this policy is published on this page with a new date.
